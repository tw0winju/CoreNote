# 코어노트 (CoreNote) — 로컬 RAG 학습 도우미

PDF·DOCX·TXT·웹페이지를 색인해두고 **내 자료 전체에 질문**하면, 관련 부분을 찾아 **출처와 함께** 답해주는 학습 도우미입니다.
임베딩·검색·답변이 전부 내 컴퓨터(Ollama)에서 돌아가서 **API 비용 0원**, 데이터도 밖으로 나가지 않습니다.

> 환경: **Windows 10 64bit** / Node.js 18+ / Ollama / 권장 GPU VRAM 8GB(RTX 3070급)

## 주요 기능

- **RAG 질문 답변** — 하이브리드 검색(벡터 코사인 + BM25) + RRF 통합으로 관련 조각을 찾아 출처와 함께 답변
- **문서 요약** — 문서를 자동 요약하고 결과를 캐싱. 원본 텍스트와 요약을 나란히 비교 가능
- **퀴즈 생성** — 색인된 문서에서 객관식 퀴즈 자동 생성
- **폴더 관리** — 문서를 폴더로 분류, 드래그 없이 드롭다운으로 이동
- **URL 색인** — 웹페이지 URL 입력만으로 색인
- **OCR 지원** — 스캔 이미지 PDF도 Tesseract로 텍스트 추출 (한국어+영어)
- **설정 UI** — 모델명·청크 크기·TOP_K·HyDE·재순위화를 UI에서 변경 가능
- **다크/라이트 테마** — 토글로 즉시 전환

## 1. 사전 준비 (최초 1회)

1. **Node.js 설치** — https://nodejs.org (LTS, Windows .msi)
2. **Ollama 설치** — https://ollama.com/download (Windows). 설치 시 백그라운드 자동 실행.
3. **모델 2개 받기** — PowerShell 또는 명령 프롬프트에서:
   ```powershell
   ollama pull qwen3:8b     # 답변 생성
   ollama pull bge-m3       # 임베딩(검색) · 한국어에 강함
   ```

## 2. 실행

가장 쉬운 방법: 폴더의 **`start.bat` 더블클릭** (최초 1회 자동 의존성 설치).

또는 터미널:
```powershell
npm install        # 최초 1회
npm run dev
```
실행 후 브라우저에서 **http://localhost:5173** 접속.

프로덕션 빌드:
```powershell
npm run build
npm start          # http://localhost:3001
```

## 3. 사용 흐름

| 탭 | 설명 |
|----|------|
| **대화** | 문서에 질문하고 출처를 확인 |
| **학습** | 문서 요약 보기·퀴즈 풀기·즐겨찾기 관리 |

1. 왼쪽 사이드바 **내 자료**에서 PDF/DOCX/TXT 파일 또는 웹페이지 URL을 추가하면 자동으로 색인됩니다.
2. **대화** 탭에서 질문을 입력하면 관련 조각을 찾아 답하고 출처를 보여줍니다.
3. **학습** 탭 → **문서요약**에서 선택 문서의 요약을 생성하고, "원본 보기"로 원본과 나란히 비교할 수 있습니다.
4. **학습** 탭 → **퀴즈**에서 선택 문서로 객관식 퀴즈를 생성해 풀어볼 수 있습니다.

## 동작 구조 (RAG)

```
[색인]
  파일/URL → 텍스트 추출(PDF/DOCX/TXT/OCR) → 청크 분할(기본 1200자, overlap 200자)
  → 임베딩(bge-m3) → LanceDB(data/lancedb/) 저장

[질문]
  질문 → (HyDE: 가상 답변 생성) → 임베딩
  → 벡터 검색 + BM25 → RRF 통합 → (재순위화)
  → 관련 조각 + 대화 맥락 → qwen3:8b → 답변 스트리밍 + 출처
```

## 자주 나오는 문제

- **"Ollama에 연결할 수 없어요"** → Ollama 실행 확인(`ollama list`). 설치 후 보통 자동 실행.
- **"임베딩/답변 모델이 없어요"** → 위의 `ollama pull` 2개 실행.
- **OCR이 느려요** → 스캔 PDF는 페이지당 렌더링 + OCR로 시간이 걸립니다. 페이지 수가 많으면 그만큼 오래 걸립니다.
- **답변 품질이 낮아요** → 설정 UI에서 `MAX_CHUNK_CHARS`를 줄이거나 `TOP_K`를 늘려보세요.
- **색인 데이터 초기화** → `data/` 폴더 삭제.
